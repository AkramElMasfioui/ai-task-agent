\# AI Task Agent



An AI task agent built with Python, Gemini, and LangGraph.



\## Features



\- AI-powered task handling with Gemini

\- Tool calling for mathematical operations

\- Sequential tool execution

\- Workflow orchestration with LangGraph

\- Automated tests with pytest



\## Technologies



\- Python

\- Google Gemini API

\- LangGraph

\- Pytest



\## Setup



1\. Create a virtual environment.

2\. Install the project's dependencies.

3\. Configure your `GEMINI\_API\_KEY` in a `.env` file.

4\. Run the application.
